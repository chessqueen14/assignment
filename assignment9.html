YouTube Component Breakdown

Main Components

1. Header

  • Logo
  • Search bar
  • Create button
  • Notifications
  • User avatar

2. Sidebar

  • Home
  • Shorts
  • Subscriptions
  • Library
  • History

3. Video Card

  • Thumbnail
  • Duration
  • Title
  • Channel name
  • Views + date

4. Video Player Page

  • Video player
  • Like/Share/Save buttons
  • Channel info + Subscribe
  • Comments
  • Recommended videos

Simple Structure

YouTube App ├── Header (navbar) ├── Sidebar (navigation) ├── Main Content │ ├── Category filters │ └── Video grid │ └── Video cards └── Video Page (when playing) ├── Player ├── Details ├── Comments └── Recommendations

Key Reusable Components

  • VideoCard - Display video preview
  • Comment - Single comment
  • SearchBar - Search videos
  • Button - Actions (like, share)
  • Avatar - User/channel image
